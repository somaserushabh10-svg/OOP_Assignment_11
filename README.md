# Standard Template Library (STL) in C++

## 1. Aim
To implement a C++ program using the Standard Template Library (STL) to store, sort, and reverse elements using a vector and standard algorithms.

## 2. Objectives
- To understand the concept of the Standard Template Library.
- To learn how to use the `vector` container.
- To perform insertion of elements using `push_back()`.
- To sort elements using `sort()`.
- To reverse elements using `reverse()`.
- To understand the use of iterators in STL.

## 3. Problem Statement
Write a C++ program that accepts integer elements from the user, stores them in a vector, displays the original elements, sorts them in ascending order, and reverses the sorted sequence using STL functions.

## 4. Theory / Concepts

The Standard Template Library (STL) is a collection of generic classes and functions provided by C++ to perform common programming tasks efficiently.

The program uses the following STL components:

- **Vector:** A dynamic array that can grow or shrink as required.
- **`push_back()`:** Adds an element to the end of a vector.
- **`sort()`:** Arranges elements in ascending order by default.
- **`reverse()`:** Reverses the order of elements within a specified range.
- **`begin()` and `end()`:** Return iterators that specify the beginning and end of a vector's range.

## 5. Algorithm
1. Start the program.
2. Include the required header files: `iostream`, `vector`, and `algorithm`.
3. Declare a vector to store integer elements.
4. Accept the number of elements from the user.
5. Read the elements and insert them into the vector using `push_back()`.
6. Display the original elements.
7. Sort the elements using `sort()`.
8. Display the sorted elements.
9. Reverse the sorted elements using `reverse()`.
10. Display the reversed elements.
11. Stop the program.
